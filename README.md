# Проект 3. Поиск вакансий с подключением БД

Программа позволяет получить данные о компаниях и вакансиях с сайта hh.ru, 
спроектировать таблицы в БД PostgreSQL и загрузить полученные данные в созданные таблицы.

# Инструкция по установке и использованию разработанных функций
1. Клонируйте репозиторий:
```
git clone git@github.com:4usnok/DZ2_OOP.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
# Список модулей
1. `main.py`
* Является управляющим модулем и находится в корне проекта 
* Содержит управляющую функцию `point_of_contact`
2. `work_bd.py`
* Содержит класс `DBManager`, который предоставляет работать с таблицами вакансий и компаний
* Содержит метод `get_companies_and_vacancies_count`:
Метод позволяет получать, список всех компаний из таблицы employers, так и количество вакансий из таблицы vacancies.
* Содержит метод `get_all_vacancies`:
Метод позволяет получать список всех вакансий: с указанием названия компании, названия вакансии и зарплаты и ссылки на вакансию.
* Содержит метод `get_avg_salary`:
Метод позволяет получать среднюю зарплату по вакансиям
* Содержит метод `get_vacancies_with_higher_salary`:
Метод позволяет получать список всех вакансий, у которых средняя зарплата выше средней по всем вакансиям.
* Содержит метод `get_vacancies_with_keyword`:
Метод позволяет получать список всех вакансий, в названии которых содержатся переданные в метод слова, например python.
3. `api_for_employers.py`
* Содержит класс `WorkingWithEmployers`, который предоставляет функционал работы с данными с hh.ru о компаниях и записывать данные в таблицу БД `employers`
* Содержит метод `data_employers_api`:
Метод позволяет получать api для получения данных о работодателях с сайта hh.ru
* Содержит приватный метод `__data_employers_api`:
Метод позволяет получать вызывает метод `data_employers_api` и делает его приватным
* Содержит метод `load_for_employ`:
Метод позволяет произвести загрузки содержимого таблицы employers в БД
* Содержит приватный метод `__load_for_employ`:
Метод позволяет сделать приватным загрузку содержимого таблицы employers в БД
4. `api_for_vacancies.py`
* Содержит класс `WorkingWithVacancies`, который предоставляет функционал работы с данными о вакансиях с hh.ru. Информация загружается в таблицу БД `vacancies`
* Содержит метод `data_employers_api`:
Метод позволяет получать api для получения данных о работодателях с сайта hh.ru
* Содержит приватный метод `__data_employers_api`:
Метод делает приватным метод `data_employers_api` тем самым делает приватным работу с апи
* Содержит метод `load_for_vac`:
Метод для работы с api-данными перед загрузкой содержимого таблицы vacancies в БД
* Содержит приватный метод `__load_for_vac`:
Метод делает приватным метод `load_for_vac` загрузки данных таблицы vacancies в БД

# Принцип работы модуля main.py
В `main.py`, находится управляющая функция `point_of_contact`, которая 
объединяет в себе весь функционал директории src. Функционал работы с api сервиса hh.ru, 
позволяет пользователю:
a) Получить информацию о работодателях, количестве доступных у них вакансиях и получить на них url ссылки;
б) На основе информации о компаниях, пользователь может получить информацию о вакансиях
тем самым, упростить пользователю поиск работы.

# Как работает программа ?
1. Запуск программы, осуществляется посредством запуска модуля `main.py`, который расположен в корне проекта
2. Интерфейс работы программы, примитивен и понятен. Программа обращается к таблицам БД, которые в свою очередь, 
берут данные из работы библиотеки requests для работы с апи сервиса hh.ru и в последующим, информация добавляется в таблицы на БД. 
3. Итоговый функционал программы представляет следующее:
* Просмотр информации об всех доступных компаниях и их вакансиях 
* Просмотр всех вакансий указанием названия компании, названия вакансии, зарплаты и ссылки на вакансию
* Просмотр средних зарплат по вакансиям
* Просмотр всех вакансий, у которых средняя зарплата выше средней по всем вакансиям
* Просмотр всех вакансий, в названии которых содержатся переданные в метод слова, например python
